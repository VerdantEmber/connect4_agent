## User Stories

- Casual Player
  - As a Casual Player, I want to see where the pieces are, so I can decide my next move
  - As a Casual Player, I want the AI to make a decision within about 2 seconds, so I don't have to wait.
  - As a Casual Player, I want to easily tell which column I am selecting so that I don't choose the wrong one.

- Analytical Player
  - As an Analytical Player, I want to see what the agent thinks I should have done, so that I can improve my skills.
  - As an Analytical Player, I want to see how the win probability changes as I play, so I can evaluate my moves.

- ML Engineer
  - As an ML Engineer, I want to see the win-loss ratio of different strategies, algorithms, and MCTS depths compare against each other, so I can determine the success of a given strategy.
  - As an ML Engineer, I want a real time graph of how the current model performs against previous versions, so I can measure progress.
  - As an ML Engineer, I want to see how confident the agent is in each choice, so that I can perform sanity-checks and better understand the model.
